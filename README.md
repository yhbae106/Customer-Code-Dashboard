# 판매처 통합 조회 대시보드

대웅제약 판매처/채널 마스터 엑셀을 브라우저에서 직접 불러와 조회하는 정적 대시보드입니다.

## 주요 기능
- 사업자번호, 판매처 코드/명, 실납처, 채널, 대표자, 영업담당, 사무소, 주소 통합 검색
- `조견표` 시트 기준 간납/종합/기타 자동 분류
- `조견표`의 온라인 지정값 우선 적용, 온라인 지정이 없는 `DW` 채널은 오프라인으로 파생 분류
- 채널/유형/온라인·오프라인/사무소/영업담당 필터
- Data 시트의 원본 필드와 파생 분류/통합주소 상세 조회
- 검색 결과는 최대 300건만 렌더링해 대용량 조회 시 화면 성능 보호

## 데이터 보안 방식
이 저장소는 공개 저장소이므로 원본 거래처 데이터는 커밋하지 않습니다.

대시보드에서 사용자가 직접 `.xlsx` 파일을 선택하면 브라우저 메모리에서만 처리합니다. 선택한 파일은 GitHub 또는 별도 서버로 업로드되지 않습니다.

현재 기준 파일 구조는 아래를 기대합니다.
- `Data` 시트
- `조견표` 시트

## 사용 방법
1. 대시보드를 엽니다.
2. `엑셀 선택`을 눌러 `261104 코드.xlsx`와 동일 구조의 최신 파일을 선택합니다.
3. 로딩 완료 후 통합 검색 또는 필터를 사용합니다.
4. 결과 행을 클릭하면 상세 정보를 확인할 수 있습니다.

## 참고
엑셀 파싱을 위해 브라우저에서 SheetJS CDN을 사용합니다. 회사 보안 정책상 외부 CDN 사용이 제한되는 환경이라면 라이브러리를 저장소에 포함하는 방식으로 변경해야 합니다.
