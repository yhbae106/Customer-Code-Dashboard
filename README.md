# 판매처 통합 조회 대시보드

대웅제약 판매처/채널 마스터 엑셀을 브라우저 기본 데이터로 저장해 반복 업로드 없이 조회하는 정적 대시보드입니다.

## 사용 방식
1. 최초 접속 시 `데이터 등록/교체`에서 기준 엑셀을 한 번 선택합니다.
2. 선택한 엑셀 원본은 브라우저 IndexedDB에 저장됩니다.
3. 다음 접속부터 저장된 기본 데이터를 자동으로 불러오므로 다시 업로드할 필요가 없습니다.
4. 최신 마스터로 갱신할 때만 `데이터 등록/교체`를 사용합니다.
5. `저장 데이터 삭제`로 해당 브라우저의 기본 데이터를 초기화할 수 있습니다.

## 주요 기능
- 사업자번호, 판매처 코드/명, 실납처, 채널, 대표자, 영업담당, 사무소, 주소 통합 검색
- `조견표` 시트 기준 간납/종합/기타 자동 분류
- `조견표`의 온라인 지정값 우선 적용, 온라인 지정이 없는 `DW` 채널은 오프라인으로 파생 분류
- 채널/유형/온라인·오프라인/사무소/영업담당 필터
- Data 시트의 원본 필드와 파생 분류/통합주소 상세 조회
- 검색 결과는 최대 300건만 렌더링해 대용량 조회 시 화면 성능 보호

## 데이터 보안
현재 저장소는 Public이므로 원본 거래처 데이터 자체는 GitHub 저장소에 커밋하지 않습니다.

대표자명, 주소, 영업담당 등 데이터는 사용자의 브라우저 내부 IndexedDB에만 저장됩니다. 같은 PC라도 브라우저나 브라우저 프로필이 달라지면 최초 1회 등록이 다시 필요합니다. 브라우저 데이터 삭제 또는 사이트 데이터 초기화 시에도 다시 등록해야 합니다.

## 기준 파일 구조
- `Data` 시트
- `조견표` 시트

## 참고
엑셀 파싱을 위해 브라우저에서 SheetJS CDN을 사용합니다. 회사 보안 정책상 외부 CDN 사용이 제한되는 환경이라면 라이브러리를 저장소에 포함하는 방식으로 변경해야 합니다.
